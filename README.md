# Install on Device

The archive can provide an **Install App** button for each IPA file.

For a GitHub Pages implementation, the links can point to the corresponding IPA files stored in the repository:

```html
<a href="ipa/Animal%20Sounds%202.0.ipa" download>
  Install App
</a>
```

For example:

```text
IPA Archive/
├── README.md
├── index.html
├── styles.css
├── script.js
├── ipa/
│   ├── Animal Sounds 2.0.ipa
```

## GitHub Codespaces

Open the repository in GitHub Codespaces to edit the archive website and its metadata.

Recommended project files:

```text
README.md
index.html
styles.css
script.js
ipa/
.devcontainer/
└── devcontainer.json
```

## GitHub Pages

The website can be published from the repository using:

**Repository → Settings → Pages → Deploy from a branch**

Select the branch containing the website files and the appropriate folder.

## Archive Format

Each IPA is represented as an iOS application package containing an application bundle:

```text
Application.ipa
└── Payload/
    └── Application.app/
        ├── Info.plist
        ├── Application
        ├── Icon.png
        └── Resources/
```

## Compatibility

The **Minimum OS** values above describe the historical minimum iOS versions supplied for these archive entries. Actual installation on a device also depends on the device, signing/provisioning, architecture, and the installation method.

## Preservation Notice

This repository is intended to document and preserve application metadata and historical package information. Only distribute IPA files when you have the appropriate rights or permission to redistribute them.
